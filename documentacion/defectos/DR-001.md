### Descripción del Defecto
Al registrar un usuario en la tienda (`index.php?route=account/register`), el campo de entrada `Telephone` solo valida una longitud entre 3 y 32 caracteres, pero no restringe ni valida que los caracteres ingresados correspondan a dígitos numéricos o a un formato de teléfono válido. Se permite el ingreso de texto arbitrario (ej. `"telefono_falso!#$"`), completando el registro exitosamente.

### Pasos para Reproducir
1. Navegar a la página de registro: `index.php?route=account/register`.
2. Completar los campos obligatorios con datos válidos (`First Name`, `Last Name`, `E-Mail`, `Password`, `Password Confirm`).
3. En el campo **Telephone**, ingresar una cadena no numérica: `TextoInvalido$$$`.
4. Marcar la casilla de aceptación de la Política de Privacidad.
5. Hacer clic en el botón **Continue**.

### Resultado Esperado
El sistema debe validar el formato del número telefónico y mostrar un mensaje de error como:  
`"Telephone number must contain only digits and valid country prefix!"`, impidiendo el registro hasta que se ingrese un número válido.

### Resultado Obtenido
El formulario acepta el texto sin validación de tipo numérico, envía la petición y redirige a `route=account/success`, registrando un cliente con número inválido.

### Impacto
- Almacenamiento de información no fidedigna en la base de datos de clientes.
- Imposibilidad de contactar al cliente para confirmación de pedidos, entregas por paquetería o soporte.
